## How to use

1. **Drag and drop PDF files** onto the box, or choose files from your device. You can add more files at any time — new files are added to the end of the list.
2. **Check the order.** The files merge in the order shown, top to bottom. Use the up and down arrows next to a file to move it, or the × button to remove it. **Clear all** empties the list and starts over.
3. **Set an output name**, or leave it blank for the default, `merged.pdf`. An unsafe or empty name is cleaned up automatically rather than rejected.
4. Select **Download merged PDF**. The files are combined in your browser and the result downloads immediately — nothing is uploaded anywhere.

**What PDF Merge does:** it combines the PDF files you select into a single PDF, in the order you choose. It does not edit page content, compress the result, or attempt OCR — it only combines whole pages from each file into one document.

## Method

**Files are processed in your browser where supported.** No file upload is required for this tool — every PDF you add is read and combined on your own device, and the merged file is generated and downloaded without ever leaving it.

**What may not be preserved.** Bookmarks, forms, annotations, signatures, attachments, layers, and some other advanced PDF features from the original files may not carry over into the merged document. Verify the merged PDF before sending, printing, filing, or publishing it.

**File size and browser limits.** Each PDF can be up to 25 MB, the combined total up to 75 MB, and up to 20 files can be merged at once. Very large, encrypted, password-protected, or corrupted PDFs may fail in the browser — these are honest, stated limits for a tool that runs entirely on your device, not a server.

**Common errors.** A specific, plain-English message explains exactly what went wrong: no files selected, a file that isn't a PDF, a file or combined total over the size limit, more than 20 files, a password-protected or encrypted PDF, or a corrupted PDF that can't be read. Do not use this tool for documents you are not allowed to process.

## FAQ

### Is PDF Merge free?

Yes. It's free and unlimited, with no sign-up and no ads.

### Are my files uploaded anywhere?

No. Every file you add is read and merged in your own browser. No file upload is required for this tool.

### What order do the files merge in?

The order shown in the list, top to bottom. Use the up and down arrows to reorder a file before merging.

### What happens to bookmarks, forms, or signatures in my PDFs?

They may not be preserved in the merged file. Verify the result before relying on it, and treat this as a simple combine, not a full-fidelity PDF editor.

### Why did my file fail to merge?

The most common reasons are a password-protected or encrypted PDF, a corrupted file, a file that isn't actually a PDF, or a file or combined total over the stated size limit. The error message names the specific problem and, where relevant, the file.

### Can I merge password-protected PDFs?

Not in this version. A password-protected or encrypted PDF returns a clear error rather than prompting for a password.

### Is there a file size limit?

Yes: 25 MB per file, 75 MB combined, and up to 20 files. These limits are stated honestly because everything runs in your browser, not on a server.

## How to use

1. In Project Setup, configure your project name, geographic location, building classification, floor count, site/portion division, and code standards (IS 456 for concrete, IS 1786 for reinforcement).
2. Attach vector drawings (architectural plans, structural layouts, sections, and member details) in the Drawing Package. Drawings remain private and are stored solely in your local browser storage.
3. Review your Project Summary metrics: structural member counts across footings, columns, beams, and slabs, pending drawing revisions, and active revision timestamps.
4. Track your construction delivery progress across the 6-step Workflow Roadmap from Drawing Intake through BBS schedule generation to Revision and Quantity comparison.
5. Review recent member calculations in Recent Work or jump into member detailing using Getting Started quick triggers.

## Method

Concrete volumes are derived from strict geometric dimensions:
- Rectangular footings and slabs: length × width × depth.
- Columns and beams: length × width × depth (or height) × same-size member count.

Reinforcement cutting lengths and bar bending schedules adhere to Indian Standard specifications:
- Method A (IS 2502:1963): Uses code bend allowance B and hook allowance H (Table II) with factor k based on steel grade, and applies Cl. 5.1.1 rounding to the next greater whole 25 mm.
- Method B (Site Practice): Uses empirical bend deductions (1d for 45°, 2d for 90°, 3d for 135°, 4d for 180°) and net cutting lengths without arbitrary length roundups.
- Unit weight of reinforcing steel: Computed using the standard density formula w = d² / 162.2 kg/m derived from steel density (7850 kg/m³).

Every calculated value traces back to its member definition and calculation method. Older project revisions are preserved as immutable snapshots, enabling accurate quantity delta tracking across revisions.

## Worked example

For an isolated footing (F1) with length 2000 mm, width 1500 mm, depth 400 mm, clear cover 50 mm, and 12 mm bottom mesh bars at 150 mm c/c:
- Concrete volume: 2.0 × 1.5 × 0.4 = 1.200 m³.
- Mesh X rebar (11 bars, cut length 2.050 m under IS 2502 Method A k=3): total length = 22.550 m, weight = 20.024 kg.
- Mesh Y rebar (14 bars, cut length 1.550 m under IS 2502 Method A k=3): total length = 21.700 m, weight = 19.270 kg.
- Total footing rebar weight = 39.294 kg.

## FAQ

### Is my project data or drawing files uploaded to any server?

No. Construction Project Planner operates 100% locally on your computer inside your web browser. No project details, dimensions, structural members, or drawing files are ever sent to an external server or cloud service.

### Which drawing file formats are supported?

The tool supports vector PDF and image drawings (PNG, JPEG, WebP). DWG CAD files are proprietary binary formats and cannot be read without external server processing or heavy plugins; please export CAD sheets to PDF or high-resolution raster images before attaching them.

### What happens if I close my browser or clear browser data?

All project data and drawing attachments are stored in your browser's local IndexedDB database. While data persists across browser sessions and tabs, clearing browser website data will remove locally saved projects. Use the Export button to save a local project file (.json) backup to your computer at any time.

### Which calculation methods are available for rebar cutting length?

The planner supports both Method A (IS 2502:1963 code allowance and 25 mm rounding) and Method B (standard site practice bend deductions). Each Bar Bending Schedule row explicitly displays which method was applied.

### Does this replace an engineer's certified structural design?

No. Quantities and Bar Bending Schedules generated by this planner are estimation and planning aids. Structural sizing, reinforcement detailing, and final construction quantities must always be reviewed and approved by a qualified licensed structural engineer.

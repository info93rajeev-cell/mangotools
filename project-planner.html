MangoTools Project Planner

Page 1: Project Intent

Goal: Build a professional utility tool website that brings organic search traffic and promotes MangoPie.in.

  • Brand: MangoTools by MangoPie.
  • Best domain: tools.mangopie.in.
  • Users: engineers, surveyors, logistics teams, medical staff, developers, legal users, creators, and office workers.
  • Core idea: free useful tools first, then paid professional exports.
  • Technical direction: client-side JavaScript where possible so server cost remains low.

Page 2: MVP Build Plan

  1. Rise & Fall Leveling Calculator: first working prototype.
  2. Bowditch Traverse Calculator: second civil/surveying tool.
  3. Medical PII Scrubber: privacy-first B2B utility.

MVP Features

  • Homepage with all tool ideas.
  • Individual tool pages.
  • Free manual input and live result preview.
  • Privacy message: processed locally in browser.
  • Export button with MangoPie promotion screen.
  • Disclaimer for professional tools.

Page 3: Profit Model

Free Plan

  • Free on-screen calculation.
  • Manual entry.
  • Basic result preview.
  • No login for simple tools.

Paid Plan

  • ₹249/month target price.
  • ₹1,999/year target price.
  • CSV/XLSX import.
  • PDF and Excel export.
  • Bulk processing.
  • Company branding on reports.
  • Saved projects.

Page 4: Launch Roadmap & Risk Control

Phase 1

  • Complete UI prototype.
  • Complete Rise & Fall Calculator logic.
  • Add basic PII Scrubber.
  • Create SEO-friendly landing page copy.

Phase 2

  • Add CSV import.
  • Add PDF/Excel export.
  • Add mobile-friendly table editing.
  • Add report templates.

Phase 3

  • Add Google login.
  • Add Razorpay subscription.
  • Add free vs pro export limits.
  • Add dashboard and saved projects.

Risk Control

  • Use validation-only disclaimer on professional tools.
  • Do not claim medical, legal, aviation, or engineering final authority.
  • State clearly when files are processed locally.
  • Keep interface ad-free and professional.

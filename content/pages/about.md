BeyondTheAI is a set of free, practical browser tools for work where the answer has to be clear and
checkable: GST and pricing calculations, logistics and construction quantities, export invoices and
packing lists, PDF and image files, and everyday developer data. The tools are in public beta.

BeyondTheAI is operated by **TANISHKA ONLINE**, Delhi 110091, India.

## The current tools run in your browser

A tool page shows "Runs on your device" only when the tool declares no network use and its engine
runs in your browser; the site's build checks this for every tool. Every tool listed on the site
today meets that test.

- When you open a page, your browser downloads the page and the program code the tool needs from
  this site.
- The numbers, text and files you then enter into a current tool are processed on your own device.
  They are not uploaded.
- File tools read the PDF or image you choose, create the result in your browser, and give it back
  to you as a download.
- Search matches what you type against a list of tools downloaded from this site.

The [Privacy](/privacy) page explains what your browser downloads, what the site stores in your
browser, and what our hosting provider handles.

## Not an AI processing service

The name BeyondTheAI does not mean the tools run on AI. Results come from fixed formulas and rules
written as ordinary program code; no AI model takes part in calculating, rounding, validating or
choosing a result.

For the calculators, the same input gives the same result, and each result shows its working so you
can check it. Image tools use your browser's own image encoder, so the exact bytes of an output file
can differ slightly between browsers, and the Timestamp Converter shows local time in your
browser's time zone.

## What the tools are — and are not

- Results depend on the values you enter and on the rules each tool page explains. Check them before
  you rely on them. See the [Disclaimer](/disclaimer).
- The Export Commercial Invoice and Export Packing List generators prepare drafts. They do not file
  anything with customs, a courier, a bank or any government portal.
- There are no accounts or sign-ups, no advertising and no third-party trackers.
